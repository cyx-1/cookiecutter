## cookiecutter-aws-lambda

This project provides a Cookiecutter template for creating AWS Lambda Python projects.

### Features
- Python 3.11+ compatible
- Uses uv for dependency management
- Includes configuration for black, flake8, and mypy

### Usage
1. Install dependencies with `uv sync`.
2. Customize your Lambda function in `index.py`.
3. Use `update.py` to package and deploy your Lambda to AWS.
